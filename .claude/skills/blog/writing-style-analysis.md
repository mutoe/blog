# mutoe 博客写作风格演变分析

> 由 Claude 于 2026-04-16 分析，基于 2016-2024 年间全部 48 篇博客文章。

---

## 第一阶段：2016-2017（起步探索期）

这个时期有 14 篇文章，涵盖**科普**、**教程**、**心得**、**随笔**四种类型。

**整体风格：热情的新手分享者**

- **开头方式**：喜欢用**痛点/场景引入**（"在用了一段时间 Hexo 后, 发现..."），科普文用**生动情境引起共鸣**（"阿洗吧, 本来快乐的心情一下子变得很糟糕啊"）
- **语气**：非常口语化，像跟朋友聊天。大量使用网络用语（"[滑稽][滑稽]"、"该死的网站管理员!!"），用"感觉"作为高频口头禅
- **读者称呼**：教程中用敬称**"您"**，心得/科普用"你""你们"。会自称"博主"
- **技术呈现**：步骤编号清晰，喜欢**列举多方案对比**再给推荐。不回避展示踩坑过程
- **标点特征**：中文语境下统一使用**英文半角逗号**（"垃圾, 就想"），这是最显著的排版特征
- **结尾惯例**：几乎必有"参考文章/资料"链接，部分文章明确标注"未完待续"
- **独特表达**："就可以啦"、"感觉很完美"、"这里就不再阐述了"、"简单介绍一下"
- **比喻能力强**：将端口比作"房间里的插座"，将清理垃圾比作"用时间换空间"

---

## 第二阶段：2018-2019（技术成长期）

这个时期有约 18 篇文章，以**心得**为主，也出现了深度**教程**（TDD 系列、testcafe）和**笔记**。

**整体风格：自信的技术实践者**

- **开头方式**："最近"成为高频开场词（"最近在项目中..."），也出现了**情景模拟式**开头（"为什么要上 TypeScript"连用三个重复场景制造戏剧效果）
- **语气升级**：自嘲更多且更有趣（"真是为难我这个英语渣了"、"万物皆 Any"、"[掀桌.jpg]x2"）。开始用 `<ruby>` 注音做隐藏幽默（"聪明"注音为"tou lan"）
- **读者称呼**：从"您"转变为**"我们"**，营造共同探索氛围（"我们来启动它吧！"）。不再用敬称
- **技术呈现进化**：
  - 大量使用 **diff 格式**展示代码增量修改（红绿对比）
  - 出现**逐行解释**（":1"、":2-9" 行号标记）
  - 嵌入 StackBlitz 在线编辑器、`<details>` 折叠标签
  - 先实践后原理，附带测试验证和 benchmark 数据
- **标点变化**：开始**混用**中英文逗号，过渡期特征明显
- **独特表达**："BB 这么多没用，Show your code!"、"awesome xxx!"、"。。。"表达无奈

---

## 第三阶段：2020-2024（成熟沉淀期）

这个时期有约 16 篇文章，类型更丰富：深度**教程**系列（TDD 续篇）、**心得**、**笔记**、长篇**随笔**（AI 思考）。

**整体风格：从容的经验分享者**

- **开头方式**：更加多样化。心得文用**真实经历+情感**开头（"颤抖的双手，激动的心情，我想哭得心都有了"）；笔记类用**模板化声明**（"这里记录了一些...可以作为避免踩坑和速查手册"）；观点文有**免责声明**
- **语气成熟但仍亲切**：口语化更自然（"emmm"、"啊，舒服"、"好，话不多说"），自嘲更克制（"由于本人技术垃圾"）。开始引用朋友/同事的话增加真实感
- **叙事能力飞跃**：前端测试优化一文作者自称"长文预警，建议当短篇小说看"，用起承转合的**故事结构**讲技术排查过程，有"信仰崩塌"、"水落石出"的戏剧性。AI 文章展现了深度思辨能力
- **emoji 开始出现**：2022 年后适度使用（😍😏😌），但不泛滥
- **技术呈现成熟**：
  - 代码块标注文件名（`` ```ts user.service.ts ``）
  - 教程从 `# 0.` 开始编号（程序员习惯）
  - 使用 `<figure>` + `<figcaption>` 给图片加说明
  - 架构图说明整体方案
- **标点趋于稳定**：中文逗号使用增多，但仍与英文逗号混用
- **独特表达**："好, ..." 成为段落过渡的高频词、"当当当当~"、"小命要紧，小命要紧"
- **特殊修辞**：三个"我不知道"排比段落做深度反思，技术博客中少见的文学手法

---

## 贯穿全部时期的核心风格特征

| 特征 | 说明 |
|------|------|
| **探索性叙事** | 从不隐藏踩坑过程，完整展示"问题→尝试→失败→解决"的旅程 |
| **"我们"共建感** | 后两个阶段一直用"我们"引导读者，像朋友在旁边手把手教 |
| **口语化+幽默** | 语气词丰富（"啦""啊""好"），自嘲和网络梗穿插 |
| **diff 格式** | 代码修改必用红绿 diff 对比，主动解释格式含义 |
| **`<!-- more -->` 截断** | 每篇都有，放在引言后、正文前 |
| **参考资料结尾** | 几乎每篇文章必有，注重知识溯源 |
| **中英混搭** | 技术术语保留英文，口语中偶尔混入英文感叹 |
| **真实情感** | 不掩饰个人生活（爱人、同事），表达激动/沮丧/好奇的真实情绪 |

## 风格演变轨迹

```
2016 ─── 热情但略显生涩 ─── "您"、"博主"、网络梗密集
  │
  ├── 标点：全英文半角
  ├── 自称：博主 / 我
  └── 读者：您 / 你们

2018 ─── 自信的技术叙事 ─── "我们"、diff 格式、StackBlitz
  │
  ├── 标点：中英混用过渡期
  ├── 自称：我
  └── 读者：我们

2020 ─── 从容的故事化表达 ─── 叙事弧线、深度思辨、情感真实
  │
  ├── 标点：趋于稳定
  ├── 自称：我
  └── 读者：我们 / 大家

2026 ─── AI 辅助写作期 ─── ???
```
